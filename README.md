# Yamato Implant

Mod de integração para Minecraft 1.20.1 com Forge. A troca do Ornn transforma uma Yamato DMC4 na bainha e um Fragmento do Oráculo Antigo em uma Yamato DMC5.

A versão 1.1.3 também adiciona a conquista **A Lâmina Desperta**, uma cena de despertar com música e partículas e comandos de operador para testar esses efeitos. Consulte o [changelog](CHANGELOG.md) para ver as mudanças desde a versão 1.0.3.

## Compilar

Com Java 17 instalado, execute `gradlew.bat build` no Windows. O JAR versionado será criado em `build/distributions/`.
